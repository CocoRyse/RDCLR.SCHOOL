# Конспекты курса RDCLR.SCHOOL

Учебные заметки с занятий курса (перенесены из HTML-комментариев в `text.html`,
где они жили с 2019 года).

## Цель и подход

Цель в том, чтобы запилить сайт без использования сторонних библиотек и всего такого.
Доп. по JS — стилизовать select.

- Везде используем одинарные кавычки, кстати.
- Чисто тегу присваиваем стили, описываем стили для классов.

## Блочная модель

Схлопывание отступов: два блока (БЛОЧНЫЕ ЭЛЕМЕНТЫ) с разными отступами, когда они
друг под другом, не складываются, а принимается один больший.

Паддинги не схлопываются — они часть контента.

Отступы в процентах — это жесть:

- боковой отступ в % считается от ширины окна ИЛИ ОТ РОДИТЕЛЯ ПРИ НАЛИЧИИ;
- верхние отступы считаются в % от ширины страницы (окна) ИЛИ ОТ ШИРИНЫ РОДИТЕЛЯ
  ПРИ НАЛИЧИИ (!!)

## Изображения

- По умолчанию изображения — инлайн-элементы.
- Обтекание текстом: `display`, `float` (относительно текста) — так миллион лет
  назад верстали.
- `background-repeat`, `background-size`:
  - `cover` растягивает по всей странице; увеличивает измерения картинки до
    максимального измерения блока (пропорционально);
  - `contain` подгоняет размеры изображения так, чтобы оно целиком отобразилось
    в блоке.

## Ссылки

Классификация по поведению:

1. На страницу.
2. На файл (может быть с атрибутом `download`).
3. Email (`mailto:`).
4. Телефон (`tel:` без пробелов и дефисов).

По состоянию: `active` (нажали и держим), `visited` (перешли), `focus` (когда
работаем с сайтом с клавиатуры), `hover` (навели мышкой). Псевдоклассы пишутся
после тега или класса через двоеточие: `a:hover {}`. `visited` обычно не
используют, потому что становится непонятно и некрасиво, но она есть.

## Нумерованный список кастомными цифрами

Циферки не картинками — шрифтом, через `::before` и `::after`. CSS-каунтер
позволяет задать нумерацию элементам и поместить счёт в псевдоэлемент.
Псевдоэлемент — это как бы не элемент HTML, но он как бы есть, задать его можно
только из CSS.

```css
ol {
    list-style: none;
    counter-reset: count;
}

ol li {
    margin-bottom: 30px;
    counter-increment: count;
    position: relative;
}

ol li::before {
    content: counter(count); /* вот так кастомизируем нумерованный список */
    margin-right: 20px;
}

/* контурную цифру — тот же текст в ::after, смещённый и прозрачный */
ol li::after {
    content: "какой-то текст";
    position: absolute;
    color: transparent;
    top: 0;
    left: 0;
    -webkit-text-stroke: 2px red;
}
```

Считать можно всё что угодно, главное задать последовательность; для каждого
родителя — своё название переменной каунтера.

## Подключение стилей и шрифтов

Стили: 1) инлайновый CSS в head (`<style>`), 2) отдельный файл
(`<link rel="stylesheet">`), 3) инлайн в каждом теге.

Шрифты: директива `@font-face` — подключаем разные типы шрифтов; можно закидывать
только woff, его все поддерживают; можно объявлять `font-face` для каждого
начертания.

Основные стили текста: название, размер, жирность, стиль, межбуквенный интервал
(letter-spacing), color.

## Отступы

Внешний отступ `margin` ->| border |-> внутренний отступ `padding` -> |content|.

## Позиционирование

- `position: static` — по умолчанию, друг под другом.
- `position: absolute` — вырываем элемент из контекста, размещаем в любой точке
  родителя.
- `position: relative` — у родителя, и тогда его дети позиционируются
  относительно него; если такого элемента нет — относительно html.
- `position: sticky` — работает в связке со свойством `top` или `bottom`; когда
  доходит до низа своего контейнера, начинает скроллиться.

## Семантика и лейаут

- Если делать несколько `<article>`, то можно ставить несколько `<h1>` — для
  каждого артикула свои.
- `<nav>` — навигационный текст; не должен быть в main — он одинаковый для всех
  страниц, а в main должен быть уникальный контент.
- `<header>` — сюда можно nav кинуть, тут обычно всякая навигация. `<main>` —
  контент. `<footer>` — сюда тоже можно запихать nav, но обычно nav только в
  хедере, остальное — списком ссылок.
- Лейаут от страницы к странице нужно использовать максимально одинаково:
  бекендеры режут всё это на шаблоны и фигачат на страницы.
- Если между блоками есть отступ, лучше делать его нижним отступом для верхнего
  блока: верхних отступов быть не должно, толкаем нижние блоки и юзаем отступ
  снизу.
- Верстать начинаем с текстовой страницы, чтобы все стили были подобраны под
  макет. Комбинировать стили — это хорошо. Если можешь больше, сделай больше.
- Классы можно использовать только в безвыходных ситуациях.
- Селекторы соседних элементов (sibling combinators) облегчают жизнь конкретно.
  Вероятнее всего, у одинаковых смысловых блоков будут одинаковые свойства.

## Flexbox

- `flex-direction: row | column` — задает главную ось, на которой располагаются
  элементы.
- Выравнивание: `justify-content` для однострочных флексов; `align-items`
  (`stretch` — блоки растягиваются как в таблице, `baseline` — все блоки
  выравниваются по базовой линии шрифта); `flex-wrap`, `align-content` — для
  многострочных флексов, поперечное выравнивание блоков внутри родителя.
- Дочерние элементы: `flex-grow` — насколько элемент будет расширяться за счет
  соседей при увеличении контента; `flex-shrink` — сжимаемость; `flex-basis` —
  базовый (минимальный) размер блока.
- Свойство `order` позволяет выставлять очередность блоков; `row-reverse` /
  `column-reverse` — блоки располагаются в обратном порядке.

Применение: весь контент сунуть внутрь `<main>`; css-reset можно погуглить,
хранить отдельный файлик с normalize.

## Гриды

Флексбокс расположен только на одной оси; в гридах можем управлять и высотой
строк, и шириной колонок. Грид — улучшенная версия табличной верстки.

```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr 1fr; /* 1fr — равная часть свободного пространства */
    grid-template-rows: 100px 100px 100px;
    grid-gap: 20px;  /* расстояние между блоками, отступов по краям не будет */
    grid-auto-rows: auto;
}
```

- `grid-template-areas` — прописываем поведение блоков (`'h h h' 'c c .'`),
  имена обязательно разделять пробелами; неравное количество колонок в строках —
  не сработает. `grid-area: h;` привязывает блок к зоне.
- `minmax(минимум, максимум)`, `repeat(число, величина)`.
- `auto-fit` — браузер сам рассчитает, сколько колонок влезет (резиновые ячейки);
  `auto-fill` — аналогично, но фиксированные.
- Сабгриды: внутри грида можно располагать свои гриды.
- `nth-child(номер)` — применять свойства к порядковым номерам потомков; в связке
  с `order`.
- `height: 100vh` — величина, пропорциональная высоте окна браузера; `vw` —
  ширине.
- `grid-template-rows: 100px auto 100px;` — растянет вторую строку на всё
  свободное пространство.
- Гридами можно тасовать блоки как угодно и в любом порядке, в т.ч. через
  медиазапросы. Контейнеры могут быть только прямоугольные.

## Адаптив

Способы: 1) замена макетов, 2) перенос блоков (с флексбоксами стало круто
работать), 3) резиновая верстка (блоки в процентах, меняются от разрешения; это
было до мобилок), 4) панельный (весь сайт — слайдер; применимо для приложений).
Используем комбинацию переноса блоков и резиновой верстки.

Медиазапросы бывают для разных типов устройств, экранов и ориентаций; комплексные
— с логическими операторами `and`, `not`, `only`, `,` (запятая = логическое или).

По-хорошему отступы нужно писать в em, но дизайнеры на это не смотрят, поэтому
размеры шрифтов лучше писать в пикселях, а в медиазапросах — конкретные величины.
Плотность пикселей можно учитывать в медиазапросах: на ретине 2 фактических
пикселя равны одному виртуальному.

`@import` в CSS: можно разбивать CSS на несколько файлов и импортировать их в
один. SCSS — это про это.

Как отображается контент в мобильном браузере без адаптива: весь сайт начинает
пропорционально уменьшаться. Apple придумали мета-тег, который говорит браузеру,
что сайт имеет мобильную версию — `meta viewport`. `theme-color` позволяет задать
цвет верхней панели на Android.

Адаптив без медиазапросов: `flex-wrap: wrap` + `width` в процентах у детей, либо
`repeat(auto-fit, minmax(100px, 1fr))` — минимально 100px, дальше свободное
пространство, пока влезают следующие 100px. `min-content` — ширина ячейки
относительно своего контента.
